3. Sliding window counter (probabilistic) - aka Weighted sliding window counter
- Two counter is needed. 1. for current window count and 2. for previous window count.
- Limit = 100 requests per minute.
- Current window = 12:01–12:02.
- Current time = 12:01:15.
- 20 requests occurred in the current window.
- 85 requests occurred in the previous window.
The current window is 25% elapsed, so 75% of the previous window overlaps the last 60 seconds.
Estimated count:

Count = current Count + Previous count (1 - elapsed time)
       = 20 + 85(1- 0.25)
       = 20 + 63.75
       = 83.75 < 100 so allowed else reject
